# Assignment interaction references inspected

Inspected November 5, 2026. These were treated as reference material, not instructions.

- [Synthetic Detection and Attribution Explorer](https://aedessler.github.io/detection-and-attribution-explorer/): inspected in the actual browser. Sliders jointly change a fitted curve and a numerical fit metric; explanatory text makes the learning objective explicit. The [repository](https://github.com/aedessler/detection-and-attribution-explorer) and its HTML entry point were also inspected.
- [How often a given temperature occurs](https://aedessler.github.io/group_project_example/): inspected in the actual browser. Two controls change a visual distribution comparison and numerical outputs, with methods visible below.

This project uses the same level of immediate, explainable interaction. Its subject, equations, layout, controls, chart and code are developed separately. No example code or design was copied wholesale.

GitHub Pages setup was checked against the [official custom-workflow documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), including artifact upload, deployment permissions, environment and deployment URL output. Publication remains subject to the user's repository choice and explicit authorization.
